# Dark dossier look replaces paper

The first browser port chose warm off-white paper and black Special Elite so the page read as a file on a desk. The product goal is to keep the Cardputer firmware's feel on the web without new screens. We decided on a near-black background, cream and blood-red type, stamps, and compact chrome—Special Elite only, no motion.

**Considered options:** Keep paper and borrow only layout; dark default with a `prefers-color-scheme` light variant; full navigation port (splash, menus). Re-skin only won: office rules and routes stay stable, and the reference identity is mostly colour and density.

**Consequences:** `.scratch/office/spec.md` stories 48–50 and related visuals are superseded by `.scratch/redesign/spec.md`. Future UI work should not reintroduce paper without revisiting this ADR.
